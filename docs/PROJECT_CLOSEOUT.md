## 版本对应

**r10 冻结工程**来自提交 `a27437dc8f56a5f4064262b1259f4be97bd21163` 的 160 个构建输入。它包含 1,548 个对象、1,029 个网格、1,925,776 个基础顶点和 158 个材质；打包后的 Blender 文件为 161,372,262 字节，SHA-256：

```text
1fe4dd221223f7eb9f1249d5981d1f639d92a94b5bd29ddd5c67709d3da573b7
```

参考 14 和 12 的实际 Cycles 预览为 800×600、32 samples、四线程、相机曝光 +0.65 EV，均已视读。它们不是 4K 最终成片。精确源码快照保留构建输入及哈希，避免与后续源码混淆。

r10 之后已合入源码的增量为 `c5f7eb2`（桌面包装实际印刷、深色地毯绒毛反光）和 `47bd56b`（三抽柜湿巾与零食包的方向、形状和图文）。这些增量经过独立实际预览与对应导出检查，**没有在收尾时重新构建整场景或替换 v1 浏览器模型**。

## 已完成与仍有差距的部分

- 完成房间布局、门窗、橱柜、微波炉、洗手台、床架、桌椅、设备、背包、行李与生活物件；保留可编辑几何、来源和参数。
- 改进了照片相机对应、木纹方向和图案、桌面设备姿态、包装、柜面、地砖、地毯、局部衣纹和细小五金。
- 床品中央翻折、衣物堆叠、背包形态、局部光照/颜色和透明塑料仍明显不够真实；实时浏览器效果与 Cycles 不同。
- 尺寸来自照片与公开床垫规格，没有取得 521 室的实测平面图。遮挡区域和柔性物件的形状存在推断。
- 照片衍生贴图保留部分拍摄光照，不能视为实测反射率。私人电脑屏幕未复制；原始照片不公开分发。

摄影测量、Gaussian splat、衣物照片拼接、被子 v7/v8 和未完的新候选均没有冒称最终成果。实验记录保留在本地 `.local/`，未验收的源码保留在本地，不合入发布构建。详细过程见 [REALISM_REVIEW.md](REALISM_REVIEW.md)。

## 复现与验证边界

原始 v1 交付仍可按 README 直接运行。复现 r10 时解压 Release 中 `room-refinement-r10-source.zip`，阅读其 `README-R10.md`，使用 Blender 4.5.13 LTS 构建；不需要私人照片。

现有交付验证检查保留 v1 native/GLB/四张成片的完整性；它不代表后续源码已重新生成对应资产，也不代表摄影级视觉验收。收尾仅做文件、源码和演示构建检查，不开展新的渲染迭代。

项目就此结束；不会自动恢复目标或继续后台改进。
